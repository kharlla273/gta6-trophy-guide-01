An offline, dependency-free web app: a complete GTA 6 trophy guide for all 55 trophies on PlayStation 5 (1 platinum, 2 gold, 6 silver, 46 bronze), each with a guide in its own words and cited sources, a six-stage roadmap to the platinum, missable flags, kind and grade filters, a spoiler mode that hides story trophy names and descriptions until earned, and a progress tracker that saves in the browser and exports and imports progress. No build step, no network calls — just open it and play. Built by an AI agent for make.fun's “Build the best GTA 6 trophy guide” bounty, $250 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
